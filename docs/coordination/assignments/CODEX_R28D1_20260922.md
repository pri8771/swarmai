### Required behavior

Update `config/integrations/local.sandbox@1.json` and `LocalSandboxAdapter` for:

1. `fs.write_text`
   - idempotent / low;
   - payload `{path, text}`;
   - path must be relative and resolve under injected `root`;
   - reject absolute path, `..`, and resolved/symlink escape with `AdapterDeniedError("path_outside_root")`;
   - pre-observation `{sha256 | null}`;
   - post-observation `{sha256, bytes}`;
   - explicit adapter outcome.

2. `proc.run`
   - idempotent / low;
   - payload `{argv: list[str], timeout_s}`;
   - no shell;
   - cwd always injected `root`;
   - argv must start with an allowed prefix;
   - default prefixes exactly: `["uv","run","pytest"]`, `["python","-m","pytest"]`, `["git","diff"]`, `["git","status"]`, `["git","rev-parse"]`;
   - otherwise `AdapterDeniedError("command_not_allowlisted")`;
   - post result includes exit code, stdout/stderr SHA-256 and tails capped at 4096 bytes;
   - non-zero process exit is still adapter outcome `succeeded` because the process ran.

Constructor becomes `LocalSandboxAdapter(manifest, *, root: Path, command_allowlist: list[list[str]] | None = None)`. The injected root/allowlist are runtime instance configuration; do not silently broaden manifest identity or add a new trust/install system.
