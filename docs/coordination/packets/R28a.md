## Why

`_outcome_from_result` returns `succeeded` on every path (`src/swarm/tools/v17_gateway.py:377-383`); any adapter exception becomes `failed` (`:162-178`); the store silently defaults to memory (`:71`). Each of these turns an uncertain external outcome into a wrong certain one.

## Surfaces

- `src/swarm/tools/adapters/base.py`
- `src/swarm/tools/v17_gateway.py`
- `src/swarm/tools/adapters/api_mcp.py` (reconcile verdict only)
- new `tests/tools/test_v17_gateway_failclosed.py`

## Exact behavior

1. `adapters/base.py` defines `AdapterNotSentError(Exception)` ("request provably never left this process") and `AdapterDeniedError(PermissionError)`, plus `ADAPTER_OUTCOMES = {"succeeded", "not_applied", "denied", "cancelled", "unknown"}`. `execute` must return a dict whose `outcome` is in that set.
2. Outcome mapping in the gateway — the only mapping:
   | Adapter result | Effect state | `state_reason` |
   |---|---|---|
   | `outcome="succeeded"` | `succeeded` | — |
   | `outcome="not_applied"` or `AdapterNotSentError` | `failed` | `not_applied` |
   | `outcome="denied"` or `AdapterDeniedError` | `denied` | adapter detail |
   | `outcome="cancelled"` | `cancelled` | — |
   | `outcome="unknown"`, missing or unrecognized `outcome`, non-dict result | `unknown` | `unrecognized_outcome` |
   | any other exception | `unknown` | `exception:<ExceptionTypeName>` |
   | deadline exceeded | `unknown` | `timeout` |
3. Use async httpx with explicit connect/read/write/total budgets for HTTP; subprocess adapters use the existing sandbox runner with terminate/kill/join. Never use `wait_for(to_thread(...))` as evidence that a mutation stopped: cancellation leaves the thread running. Legacy thread adapters must stay unknown and non-retryable until reconciled safely. Bound observe/reconcile calls too. Post-observation failure cannot erase a known successful response; record the observation failure separately.
4. `store` becomes a required keyword argument. For every operational mutating operation, including `idempotent`, if `getattr(store, "durable", False)` is not `True` → `PolicyDeniedError("durable_store_required")` before any adapter method other than `normalize`/`validate` runs.
5. `ApiMcpAdapter.reconcile`: with no prior `succeeded` receipt return `{"state": "unknown", "reason": "destination_not_observable"}` — an echo transport cannot prove non-application. It never returns `failed` or `not_applied`.
