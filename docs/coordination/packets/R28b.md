## Why

The envelope's own `side_effect_class` and `risk_class` are trusted and default to `none`/`low` (`src/swarm/contracts/actions.py:44-45`), so a caller can skip approval by mislabeling. Fences default to valid-looking values (`:48-49`) and the gateway compares them with constructor constants (`v17_gateway.py:61-70`, `:371-375`). Scopes are a static set with no actor.

## Exact behavior

1. `OperationDecl(StrictModel)`: `side_effect_class`, `risk_class`, `scopes: list[str]`, `read_data_classes: list[str]`, `write_data_classes: list[str]`. `AdapterManifest.operations: dict[str, OperationDecl]`. Operation absent from the manifest → `ToolAuthorizationError("operation_not_declared")`.
2. Effective class = the higher of envelope claim and manifest declaration, order `none < idempotent < consequential < irreversible`; risk likewise, `low < medium < high < critical`. The gateway uses only effective values. `ActionReceiptV17` gains `effective_side_effect_class` and `effective_risk_class`.
3. `ActionEnvelope.lease_generation` and `.cancellation_generation` become `int | None = None`. For effective class `consequential`/`irreversible`, `mission_id`, `task_id`, `attempt_id` and both generations are required → else `StaleLeaseError("fence_missing")`.
4. `fences.py`:
   - `FenceState(StrictModel)`: `lease_generation: int`, `cancellation_generation: int`, `authority: dict[str, Any] = {}` — reserved for V1.8; V1.7 code never reads it.
   - `FenceProvider(Protocol)`: `current(*, project_id, mission_id, task_id, attempt_id) -> FenceState` and `reader(*, project_id, mission_id, task_id, attempt_id) -> Callable[[Session], Mapping[str, int | None]]`.
   - `StaticFenceProvider(lease_generation, cancellation_generation)` for unit tests and non-leased local runs.
   - `LeaseFenceProvider(session_factory)` delegates to rule 5.
   - `ActorContext(StrictModel)`: `actor: str`, `project_id: str`.
   - `PolicyProvider(Protocol)`: `effective_scopes(*, project_id, actor, integration_id, integration_version) -> frozenset[str]`; `current_policy_version(*, project_id) -> str`. `StaticPolicyProvider(scopes, policy_version)`.
5. `db/lease_fencing.py`: `read_current_fence(session, *, project_id, mission_id, task_id, attempt_id) -> dict[str, int]` — returns `{"lease_generation": TaskAttemptRow.lease_generation, "cancellation_generation": MissionRow.cancellation_generation}`. The mission row is the cancellation authority (the same source `_assert_accept_fence` uses, `lease_fencing.py:1376`). Both rows are selected with `with_for_update(read=True)` (`FOR SHARE`). Missing mission/attempt, or a project mismatch → `LeaseClaimError("lease_not_current")`. This keeps worker tables owned by the lease module.
6. Gateway: `ConsequentialToolGateway(*, adapter, store, fences: FenceProvider, policy: PolicyProvider)` (R28c replaces `adapter` with `registry`); `execute_envelope(envelope, *, context: ActorContext)`. Checks in order: `context.project_id != envelope.project_id` → `wrong_project`; `context.actor != envelope.actor` → `actor_mismatch`; `envelope.policy_version != policy.current_policy_version(...)` → `PolicyDeniedError("policy_version_stale")`; required scopes = declaration scopes ∪ `requested_scopes`, all must be in `policy.effective_scopes(...)` → else `denied_scopes:[...]`; then `fences.current(...)` must equal the envelope's generations (`stale_lease_generation` / `cancellation_generation_mismatch`); finally `begin_execution(..., fence_reader=fences.reader(...))`. Remove constructor parameters `project_id`, `allowed_scopes`, `current_lease_generation`, `current_cancellation_generation`.
