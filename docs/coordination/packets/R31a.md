## Why

`BrowserSessionAdapter` is a simulator with no IO. The contract separates session identity, site authorization, destination, intended operation and session health; that separation has to be exercised against a real cookie session that really expires.

## Surfaces

- new `src/swarm/tools/adapters/http_session.py`

## Exact behavior

1. Manifest `http.session@1`: `adapter_class="http_session"`, `network_scopes=["http://127.0.0.1"]`, `user_interaction_consequential=true`, operations `page.open` (`none`/`low`, scope `web.read`) and `form.submit` (`consequential`/`medium`, scope `web.submit`).
2. `SessionJar`: in-process map `session_alias -> httpx.Cookies`. Never serialized, logged, or placed in an envelope, receipt, or evidence file. Envelopes carry only `session_alias` (`BrowserSessionRef`).
3. `validate`: same destination rules as `R30b` rule 3.
4. `page.open`: `GET` with the alias's cookies, `follow_redirects=False`. `200` → `succeeded` with `{"navigated_to": <path>}`. `302` whose `Location` path starts with `/login` → outcome `denied`, detail `{"reason":"session_expired","safe_destination": <original path+query>}`. Any other redirect → `denied`, `unexpected_redirect`.
5. `form.submit`: `POST` JSON `{client_ref, text}` with `client_ref = sha256(effect_key)[:32]` and the persisted per-attempt `X-Fixture-Request-ID` (R30a). `2xx` → `succeeded`. `302` to `/login` → return `{"outcome":"unknown","reason":"session_expired_during_submit","safe_destination":"/app/form"}`. The adapter does **not** decide the submit was not applied; only reconcile may.
6. `reconcile` for `form.submit`: `GET /app/submissions?client_ref=` with the alias's cookies. `302` to `/login` → `{"state":"unknown","reason":"reauth_required_to_reconcile"}`. `200` with exactly one matching row → `succeeded`; multiple matches or zero matches alone → `unknown`. For this fixture only, query authenticated `/app/requests/{request_id}` and verify exact request/payload/client_ref. Terminal/not_applied plus a stopped local sender proves `not_applied`; a missing/in_flight/mismatched receipt stays unknown. No real-site adapter inherits this fixture-specific proof capability.
7. The adapter exposes **no** login operation. `SessionJar.authenticate(alias, fn: Callable[[httpx.Client], None])` lets the recovery service (R31b) run a human-auth step supplied by the caller; the adapter never sees credentials.

## Evidence gate

## Exit

Tests green three consecutive runs; ruff and mypy clean.

## Do not

Do not drive a real browser and do not add a browser-automation dependency: the artifact is about session semantics at the action boundary. Do not store cookies on disk.

Closure invariant: no automatically retried browser submission based solely on zero search results or timeout. Include a delayed-commit test and a duplicate-object anomaly test. The fixture may expose a request-id terminal receipt for its own mechanics; no real adapter may assume such an API exists.
